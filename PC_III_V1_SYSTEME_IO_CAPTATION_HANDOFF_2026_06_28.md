# 1. Principio arquitectónico

Systeme.io es una plataforma poderosa pero muda.

Hace lo que se le configura, pero no piensa:

- no decide qué embudo crear,
- no sabe qué correo escribir,
- no entiende la industria,
- no cruza Guardian Profesional,
- no conoce ChromaDB,
- no interpreta el momento del usuario,
- no optimiza desde el organismo.

ODI asume el rol del humano experto que normalmente configuraría Systeme.io, pero lo hace escalable para cada proyecto, industria, idioma y usuario.

# 10. Workflows por organismo

## P10 · Profesional se registra

```text
IF formulario completado
THEN tag profesional_nuevo
→ email bienvenida ES/EN
→ esperar 24h
→ si perfil incompleto: recordatorio
→ si perfil completo: profesional_activo
→ enviar a verificación
→ si verificado: activar en búsquedas
```

## P10 · Cliente busca profesional

```text
IF búsqueda completada
THEN tag cliente_busca_categoria
→ ODI busca profesionales cercanos
→ email con 3 opciones verificadas
→ esperar 48h
→ si contrató: cliente_activo
→ si no contrató: alternativas + pregunta de precisión
```

## P10 · Servicio completado

```text
IF profesional marca servicio terminado
THEN pedir calificación cliente + profesional
→ esperar 7 días
→ si ambos calificaron: ciclo_completo + actualizar ranking
```

## T10 · Nuevo miembro verificado

```text
IF verificación completada
THEN tag miembro_verificado
→ bienvenida + próximos 3 eventos
→ activar en directorio
→ dar 3 invitaciones
→ esperar 14 días
→ si asistió a evento: miembro_activo
→ si no asistió: invitación contextual
```

## T10 · Evento terminó

```text
IF fecha evento pasó
THEN tag asistentes evento_nombre
→ galería 24h
→ conexiones sugeridas 48h
→ próximo evento 72h
→ si asistió a 3+ eventos: miembro_fiel + premium
```

## Guardian Profesional · Alerta de exposición

```text
IF índice exposición sube ≥ 0.5
THEN alerta personalizada con 3 acciones
→ tag alerta_activa
→ esperar 7 días
→ si ejecutó acción: recalcular índice + felicitación
→ si no ejecutó: recordatorio suave Ramona
→ si sigue sin actuar e índice ≥ 7: protocolo urgente
```

# 15. Implementación técnica

## Archivo propuesto

```text
/opt/odi/core/odi_systeme_connector.py
```

Clase:

```text
SystemeConnector
```

Responsabilidades:

- crear contacto,
- agregar tag,
- buscar contacto,
- sincronizar desde WhatsApp,
- actualizar email real,
- enviar alerta Guardian.

## captation.json

Equivalente a `brand.json`, pero para captación.

Debe incluir:

- project,
- name,
- systeme_api_key,
- systeme_sub_account,
- languages,
- funnels,
- email_sequences,
- affiliate,
- courses,
- branding.

## CaptationPipeline

Archivo propuesto:

```text
/opt/odi/core/odi_captation_pipeline.py
```

Endpoint conceptual:

```text
POST /captacion/start {"project":"P10"}
```

Pasos:

1. Leer captation.json.
2. Verificar conexión Systeme.io API.
3. Crear/actualizar embudos.
4. Crear/actualizar secuencias de email.
5. Configurar programa de afiliados.
6. Configurar automatizaciones.
7. Verificar con test contact.
8. Reportar resultado.
