# 2. Secuencia de ejecución

## Paso 1 · Crear cuenta maestra ADSI en Systeme.io Free

Objetivo:

```text
Abrir la puerta operativa de captación sin costo inicial.
```

Requisitos:

- cuenta ADSI,
- acceso administrativo,
- email corporativo o cuenta central definida,
- zona horaria correcta,
- nombre de cuenta reconocible.

## Paso 2 · Crear taxonomía de tags base ADSI/P10

Crear tags mínimos:

```text
ADSI_ORIGEN_landing_p10_profesional
ADSI_IDIOMA_es
ADSI_IDIOMA_en
ADSI_IDIOMA_bilingue
P10_TIPO_profesional
P10_ESTADO_registro_incompleto
P10_ESTADO_perfil_completo
P10_STATUS_verificado
```

Regla:

```text
No lanzar funnel sin tags creados y revisados.
```

## Paso 3 · Ensamblar funnel P10 Professional Signup v1

Nombre recomendado:

```text
P10 Professional Signup v1
```

Estructura:

```text
landing_captation
thank_you_onboarding
verification_instructions
```

## Paso 4 · Desplegar landing page ES/EN

Versión ES:

```text
No solo publiques tu perfil. Protege tu trayectoria.
```

Versión EN:

```text
Don't just publish your profile. Protect your career trajectory.
```

CTA ES:

```text
Iniciar mi registro profesional gratis
```

CTA EN:

```text
Start my professional registration for free
```

## Paso 5 · Configurar formulario progresivo de 2 pasos

Paso 1:

```text
nombre
correo_electronico
idioma
```

Paso 2:

```text
whatsapp_con_codigo_pais
rol_principal
ciudad
```

Regla:

```text
No convertir el registro inicial en interrogatorio.
Captar primero. Enriquecer después.
```

## Paso 6 · Programar secuencia bienvenida ES/EN

Crear:

```text
seq_p10_welcome_es_v1
seq_p10_welcome_en_v1
seq_p10_welcome_bilingual_v1
```

Secuencia:

1. Día 0 · El fin del directorio.
2. Día 1 · Índice de Exposición.
3. Día 3 · El poder de la Sinergia.
4. Día 5 · La insignia verde.
5. Día 7 · Tu primera alerta de mercado.

## Paso 7 · Activar workflow condicional

Workflow:

```text
wf_p10_professional_onboarding_v1
```

Lógica:

```text
Opt-in completado
→ aplicar tags de entrada
→ aplicar tag de idioma
→ suscribir a secuencia correspondiente
→ esperar 24h
→ si onboarding completo: mover a perfil completo
→ si no: recordatorio
→ esperar 7 días
→ si verificado: segmento activo
→ si no: invitación formal a verificación
```

## Paso 8 · Inyectar contacto test

Crear contacto de prueba con:

```text
nombre: Test P10
email: test+p10@dominio_controlado
idioma: es
rol: mecanico / abogado / desarrollador
ciudad: Miami
```

Luego repetir para idioma EN.

## Paso 9 · Verificación cruzada

Validar:

- tags aplicados,
- idioma correcto,
- secuencia correcta,
- redirección correcta,
- estado incompleto/completo,
- workflow 24h,
- workflow 7 días,
- no duplicidad de tags,
- no cruce ES/EN.

## Paso 10 · Evidencia browser

Entregar capturas de:

- dashboard Systeme.io con funnel creado,
- lista de tags,
- landing ES,
- landing EN,
- formulario paso 1,
- formulario paso 2,
- secuencia email,
- workflow,
- contacto test con tags aplicados.

# 3. Criterios PASS

La orden se considera PASS si:

```text
1. Funnel existe.
2. Tags base existen.
3. Landing ES/EN está visible.
4. Formulario captura correctamente.
5. Contacto test recibe tags correctos.
6. Contacto test entra a secuencia correcta.
7. Workflow no cruza idiomas.
8. Evidencia browser entregada.
```

---

# 4. Criterios FAIL

La orden falla si:

```text
1. Tags no siguen nomenclatura aprobada.
2. Usuario ES recibe secuencia EN o viceversa.
3. Formulario pierde datos.
4. No queda evidencia browser.
5. Funnel se crea como campaña genérica sin narrativa P10.
6. Se intenta construir API antes de validar configuración manual.
```
