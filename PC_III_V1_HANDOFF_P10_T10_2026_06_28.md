# 2. Expediente 001 · Profesionales10 / P10

## 2.1 Punto de partida

Profesionales10 fue reclasificado bajo la Constitución **ODI Dando Vida a Proyectos** como:

```text
Caso tipo: Directorio Muerto + Modelo Equivocado
Semáforo: AMARILLO
Veredicto: Viable con pivot
```

El problema no era solo diseño. Era categoría mental equivocada.

P10 se veía como:

- directorio profesional,
- marketplace de servicios,
- grilla de oficios,
- plataforma de contratación.

Ese enfoque dejaba por fuera a abogados, médicos, contadores, diseñadores, programadores, consultores, docentes, agentes de seguros, especialistas IA y profesiones emergentes.

## 2.2 Giro táctico aprobado

Se decidió abandonar la vitrina de servicios y convertir P10 en:

```text
P10 v3 · Terminal de Inteligencia Profesional
Organismo de protección y evolución de trayectorias
```

Frase matriz:

```text
P10 no muestra profesiones.
P10 protege trayectorias.
```

Principio de diseño:

```text
Carrera arriba. Oficios abajo. P10 presente siempre.
```

## 2.3 Componentes centrales de P10 v3

La jerarquía aprobada para P10 v3:

1. `HeroStrategic`
2. `GuardianDashboard`
3. `ExposureIndexGauge`
4. `WaveStatus`
5. `SignalAlert`
6. `ODIPresenceCareerBlock`
7. `SmartProfessionalSearch`
8. `ODIPulseFeed` híbrido
9. `ProfessionalWorlds`
10. `CareerSynergyNetwork`
11. `GrowthAndReconversionRoutes`
12. `FeaturedProfessionals` secundario
13. `ProfessionalRegistration`
14. `TrustAndGovernance`

## 2.4 Guardian Profesional integrado

P10 v3 asumió el concepto de **ODI Guardian Profesional**, convertido visualmente en:

- Índice de Exposición 0-10,
- estado profesional,
- Mapa de Oleadas,
- señales de mercado,
- rutas de fortalecimiento,
- sinergias profesionales,
- acciones recomendadas.

Regla sensible:

```text
En home pública, el índice debe ser demo o CTA.
No presentar dato personalizado real sin sesión.
No generar pánico.
Urgencia siempre con acciones concretas.
```

## 2.5 Rutas de Reconversión

Se selló la lógica obligatoria:

```text
Toda ruta de reconversión debe nacer de una señal,
conectar con una habilidad
y terminar en una acción.
```

Contrato de card:

```text

```

Ejemplos trabajados:

- Analista contable → Consultor financiero IA
